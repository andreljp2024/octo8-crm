# Octo8 — Customer Engagement Platform

## Visão Geral
O Octo8 é uma plataforma SaaS multitenant de Customer Engagement, Contact Center, CRM, Automação e Inteligência Artificial.

## Status Atual do Desenvolvimento
- [x] Roteamento Base e Layout
- [x] Dashboard Operacional VoIP
- [x] Analytics Avançado (ASR / Recharts)
- [x] **NOVO:** Omnichannel Workspace (Webchat, WhatsApp, Instagram com Copilot IA)
- [x] **NOVO:** Contact Center & Telefonia (WebRTC Phone, SIP Causes, CDR e Fila Avançada)

## Como Executar
```bash
npm run dev
```
